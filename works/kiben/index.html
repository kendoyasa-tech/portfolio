            このページについて

            試合は1打席ずつ、打者の「ミート・パワー・走力」と投手の「球威・制球・スタミナ」の数値から確率で結果を決めて進めています。9回で同点なら10回からタイブレーク、後攻がリードした時点でサヨナラになります。記事は試合の結果と名場面から、見出し・本文・監督コメントを組み立てています。

            同じ仕組みを Python で作った Discord ボット版もあり、チャットで「!試合 大阪桐蔭」と送ると記事が返ってきます。

            ページ上部の「朝刊」は、GitHub Actions が毎朝6時に Node.js でこのページと同じシミュレーターを動かし、結果を JSON に保存して Discord の Webhook に投稿する仕組みで、サーバーを用意せずに自動で更新しています。

            今後も、熱闘甲子園風のダイジェスト動画の制作などで、このページは随時更新していきます。
