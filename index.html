ABOUT

医療機関で臨床工学技士として勤務しながら、WordPressを用いたWeb制作を中心に活動しているフリーランスWebデザイナーです。

医療現場では、患者様やご家族の話を丁寧に聞き取り、専門的な内容をわかりやすい言葉に置き換えて伝えることを日常的に行っています。この対話の経験は、Web制作でお客様のご要望を整理し、本当に必要なものを一緒に見極めていく場面でそのまま活きています。

ただサイトを作るだけではなく、お客様の課題に共に向き合い、根本的な問題解決を目指します。医療現場で培ったホスピタリティのある対応と、丁寧なコミュニケーションを大切にしています。

現在はAIとプログラミングも学習中。医療現場の経験とAIを掛け合わせて、Webサイト以外の課題解決にも挑戦しています。

医療機関のご担当者さまへ

歯科医院・クリニック・治療院など、医療にたずさわる方のサイト制作を得意としています。

私は臨床工学技士として、いまも医療機関で患者様と接しています。診察を待つ間の不安、専門用語だけの説明が伝わらないもどかしさ、忙しい合間に更新作業まで手が回らない現場の事情を、実際に見てきました。

医院のホームページは、患者様が来院を決める前に必ず見る場所です。だからこそ「きれいなサイト」で終わらせず、はじめての方が不安なく予約までたどり着ける導線と、先生やスタッフの人柄が伝わる言葉づかいを大切にしています。

医療広告ガイドラインに配慮した表現の相談や、開院後にご自身で更新できる仕組みづくりまで、現場の感覚をふまえてご提案します。

  • 患者様目線での情報整理

    診療時間・アクセス・初診の流れなど、来院前に知りたい情報を迷わせずに届けます。

  • 予約までの導線設計

    Web予約・電話・LINEなど、医院の運用に合った申し込み方法へ自然につなげます。

  • 忙しい現場でも続く運用

    お知らせや診療時間の変更を、専門知識がなくても更新できる形で納品します。

歯科・美容クリニック・整骨院など、診療科を問わずご相談いただけます。まずは現在のお困りごとをお聞かせください。

歯科医院サイト

HTML・CSS・JavaScript / Web予約導線

実際のサイトを見る

制作の目的
架空の歯科医院「そよかぜ歯科クリニック」を題材に、患者様が来院を決めるまでに必要な情報と、予約までの導線を設計する目的で制作しました。医院名・住所・電話番号はすべて架空のものです。
担当範囲
構成案の作成 / デザイン / HTML・CSS・JavaScriptコーディング / レスポンシブ対応
制作期間
約1週間
課題と工夫した点
はじめて受診する方が不安に感じる「痛みへの配慮」「費用」「予約方法」を早い段階で示し、どの位置まで読み進めても予約ボタンが目に入る配置にしました。診療時間表はスマートフォンでも崩れないよう横スクロールに切り替え、電話番号はタップでそのまま発信できるようにしています。医療広告ガイドラインを意識し、効果を断定する表現は使っていません。
使用技術
HTML / CSS / JavaScript
